# Computing foundations

Build the computing mental model needed to understand programs, services, networks, and classical AI search.

## Topics

- [Backend basics](backend-basics/README.md): Linux processes, networking, DNS/TLS, HTTP contracts, and API design.
- [Classical AI](classical-ai/README.md): state spaces, search strategies, constraints, and reasoning.

**Study order:** read the backend basics in sequence; then study search and reasoning before machine learning. The examples connect protocol-level behavior to the Java/Spring services built later.
