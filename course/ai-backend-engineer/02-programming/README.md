# Programming for AI backend engineering

Java/Spring is the primary production backend route in this course. Python is included because data, machine-learning, and many model tools use it. Learn enough Python to inspect data, run experiments, and integrate model services; keep using Java for the service engineering you already know.

## Paths

- [Java and Spring Boot](java-spring/README.md): modern Java, API architecture, model integration, RAG, security, jobs, tests, observability, deployment, and system design.
- [Python engineering](python/README.md): Python fundamentals, packaging, production boundaries, FastAPI, async behavior, and testing.
- [Java/backend learning context](java-spring-context/engineering-context.md): connect existing backend experience to the AI-specific skills in the course.

Do not try to master two backend stacks simultaneously. Study the Java path deeply and use Python selectively for model/data tasks unless your target role specifically requires Python services.
