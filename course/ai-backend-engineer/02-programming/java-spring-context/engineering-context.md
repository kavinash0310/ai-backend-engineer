# Java and Backend Engineering

**Your starting strength:** Java, Spring Boot, Hibernate and microservices. The goal is to connect this knowledge to probabilistic, slow, expensive and externally hosted model dependencies.

## Reuse then extend

Review specific gaps from [Java Backend Interview Mastery](https://github.com/kavinash0310/java-backend-interview-mastery) and [AI Backend Engineer](https://github.com/kavinash0310/ai-backend-engineer). Core subjects to be able to explain:

- modern Java types, errors and concurrency;
- Spring Boot request/configuration/lifecycle boundaries;
- Spring Security authentication, authorization and tenant isolation;
- Hibernate/JPA transactions, locking, lazy loading and query behavior;
- HTTP contracts, versioning, streaming and asynchronous job APIs;
- test layers, observability, production diagnostics and rollback;
- modular monolith vs microservices and data/service ownership.

**AI-specific additions:** provider adapters and structured results; prompt/model/version traceability; time/token/cost budgets; retry/idempotency; tenant-aware retrieval; streaming cancellation; AI quality evaluation distinct from code tests.

See the [Java/Spring AI backend course](https://github.com/kavinash0310/ai-backend-engineer/tree/main/course/ai-backend-engineer/02-programming/java-spring). Completion evidence should be a code-reviewed Spring service, not a vocabulary list.
