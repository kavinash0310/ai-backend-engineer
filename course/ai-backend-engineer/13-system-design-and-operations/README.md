# System design and operations

Design, deploy, observe, and recover AI services against measurable product, reliability, latency, security, and cost requirements.

## Chapters

- [AI system design](ai-system-design/README.md): requirements, capacity estimates, latency budgets, overload, reliability, and SLOs.
- [Cloud and deployment](cloud-deployment/README.md): containers, identity, cloud resources, CI/CD, recovery, Kubernetes, and cost.
- [Backend operations](backend-operations/README.md): Docker, configuration, observability, reliability, scaling, and cloud fundamentals.

Start with architecture and capacity. Add implementation and operational controls only after defining service goals and failure behavior.
