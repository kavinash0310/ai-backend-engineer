# Projects

Projects turn course knowledge into evidence a reviewer can inspect. Build them in order; document the architecture, trust boundaries, data rights, tests, evaluation, cost/latency, failure behavior, and limitations.

## Project paths

- [Guided portfolio projects](learning-guides/README.md): start with the evidence-grounded knowledge assistant and extend it into prediction and research workflows.
- [Implementation project specifications](build-projects/README.md): model inference API, permission-aware RAG service, and production capstone.

Use the [readiness rubric](../../../assessments/README.md) and never include private or unauthorized data or credentials in a repository.
