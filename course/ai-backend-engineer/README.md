
# AI Backend Engineer — complete course from foundations to production

This repository contains **one integrated course**. Every subject, lesson, project, glossary, and study guide lives under this course directory. The sequence starts with the foundations needed to understand AI and ends with production engineering, portfolio evidence, and interview readiness.

## How to use the course

1. Start with [Getting Started](00-getting-started/README.md). Complete the diagnostic, choose a weekly pace, and use the progress tracker.
2. Learn computing and programming foundations in [Computing Foundations](01-computing-foundations/README.md) and [Programming](02-programming/README.md). Java/Spring remains the primary backend path; Python is taught for data and model work.
3. Study [Mathematics](03-mathematics/README.md) and [Data Engineering](04-data-engineering/README.md) before relying on model libraries.
4. Follow [Machine Learning](05-machine-learning/README.md), [Deep Learning](06-deep-learning/README.md), [NLP and LLMs](07-nlp-llms-and-generative-ai/README.md), [RAG](08-rag-and-knowledge-systems/README.md), and [Agents](09-ai-agents-and-orchestration/README.md) in order.
5. Apply that knowledge through [AI Backend Systems](10-ai-backend-systems/README.md), [Evaluation and MLOps](11-evaluation-and-mlops/README.md), [Security and Governance](12-security-and-governance/README.md), and [System Design and Operations](13-system-design-and-operations/README.md).
6. Build and explain the work in [Projects](14-projects/README.md), then use [Career and Interview Preparation](15-career/README.md).

You do not need a GPU to begin. Start with small datasets, local examples, or hosted model APIs. Use the Java/Spring chapters for production service implementation and learn Python where the AI and data ecosystem needs it.

## Learning principles

- Learn a concept, implement a small version, test it, and explain its limitations.
- Treat code tests and model-quality evaluations as different kinds of evidence.
- Keep security and authorization in application code; a prompt is not an access-control boundary.
- Record assumptions, metrics, dataset/model versions, cost, latency, and known failures in projects.
- Recheck official documentation for changing frameworks, provider APIs, model terms, and security guidance.
