# Baseline diagnostic

Use the marks **Can explain and demonstrate**, **Concept only**, or **Need to learn**. Skip only when you can provide evidence.

## Backend and Java

- [ ] Explain Spring bean/config/request lifecycle, validation, exception mapping and security filters.
- [ ] Explain Hibernate persistence context, dirty checking, lazy loading, N+1, transactions and optimistic locking.
- [ ] Design idempotent APIs and jobs with retries and durable state.
- [ ] Explain Java memory model, executor saturation, connection pools, heap/GC and profiling.
- [ ] Trace a production request through logs, metrics and dependencies.
- [ ] Explain when a modular monolith beats service decomposition.

Refresh only gaps from [Java Backend Interview Mastery](https://github.com/kavinash0310/java-backend-interview-mastery).

## CS

- [ ] Derive Big-O for loops and collection operations.
- [ ] Explain process vs thread, stack vs heap, memory and context switching.
- [ ] Explain DNS, TCP, TLS, HTTP, connection pools, timeout and retries.
- [ ] Write joins, aggregation, indexes and transactions with constraints.
- [ ] Explain hash maps, binary search, BFS/DFS, heaps and sorting.

Use targeted chapters from [CS Fundamentals](https://github.com/kavinash0310/cs-fundamentals) where needed.

## Python/data

Write a program that reads a CSV, validates columns, groups rows, handles malformed values and writes a result. Explain mutability, list/dict/set behavior, exceptions, virtual environments, NumPy shapes/dtypes/broadcasting and a leakage-safe split.

## Math and AI

Explain a vector and dot product; calculate mean/variance for a small list; explain conditional probability; describe derivative and gradient; explain why gradient descent subtracts the gradient; distinguish parameters from hyperparameters; explain why test data must not affect preprocessing/tuning.

Record weak areas in [Progress Tracker](Progress-Tracker.md). A familiar word is not evidence of understanding.
