# Curriculum map

| Domain | Priority | Expected evidence |
|---|---|---|
| CS foundations | Working knowledge; refresh gaps | Explain complexity, OS/network/data behavior and debug it |
| Java/backend | Strong working knowledge; existing strength | Secure Spring AI service with testable boundaries |
| Python/data | Must master for AI collaboration | Reproducible data pipeline and inference API |
| Mathematics | Must master practical intuition | Hand-worked examples checked by code |
| ML lifecycle | Must master | Baseline, leakage-safe validation, metrics and report |
| Deep learning | Must master concepts and practical workflow | Train/debug small model and explain gradients/shapes |
| LLM engineering | Must master for backend decisions | Explain request, tokenization, inference and resource trade-offs |
| RAG | Must master | Permission-aware service with separate retrieval/answer evaluation |
| Agents/MCP | Strong working knowledge | Bounded tool workflow with approvals and audit |
| Distributed systems | Must master for senior scope | Idempotent asynchronous design and failure drill |
| Cloud/operations | Strong working knowledge | Deployment, telemetry, SLO, runbook and rollback |
| Security/governance | Must master | Threat model and negative tests |
| Career/interviews | Must master | Portfolio evidence and architecture walkthrough |

## Subject sequence

1. CS + existing Java strengths
2. Python, data and math
3. Machine learning lifecycle
4. Neural networks, optimization and transformers
5. LLM training/inference and evaluation
6. RAG and knowledge systems
7. Java/Python production integration
8. Agents, workflows and MCP
9. System design, cloud, security, operations
10. Projects and interviews
