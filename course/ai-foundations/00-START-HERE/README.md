# 00 — Start Here

This section gives you the sequence, the reason for the order, a realistic study rhythm, and evidence gates.

## First steps

1. Complete [Baseline Diagnostic](Baseline-Diagnostic.md) to validate current Java strengths and identify CS, Python, math, data and AI gaps.
2. Read [Learning Roadmap](Learning-Roadmap.md) once, then follow the current week's tasks in [Weekly Study Plan](Weekly-Study-Plan.md).
3. Use [Curriculum Map](Curriculum-Map.md) to find the subject and [Prerequisite Graph](Prerequisite-Graph.md) to avoid skipping foundations.
4. Track artifacts and explanations in [Progress Tracker](Progress-Tracker.md).
5. Study [How to Study](How-to-Study.md) and [Technology Selection Guide](Technology-Selection-Guide.md) before adding frameworks.

## Completion means evidence

A chapter isn't complete because it was read. You should be able to explain its mechanism, reproduce a small example, implement or modify it, test a failure/edge case, and state one limitation. Reuse external repositories selectively after your diagnostic rather than rereading every topic from zero.
