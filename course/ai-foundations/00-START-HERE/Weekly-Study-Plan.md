# Weekly study plan — 56 weeks

Study six days per week: days 1–2 learn and work examples; days 3–4 implement; day 5 finish assignment/tests; day 6 recall, review, integrate, document. Day 7 is rest.

| Weeks | Focus and deliverables |
|---|---|
| 1–4 | Python setup and values; control flow/collections; functions/modules/exceptions; files/JSON/CSV/Git. Deliver tested CLI cleaning tool. |
| 5–8 | Environments and NumPy shapes; vectorization/Pandas; vectors/dot/matrix multiply; norms/cosine/statistics. Deliver data exploration and hand-checked numerical examples. |
| 9–12 | Derivatives/finite differences; probability/Bayes; distributions/sampling/intervals; loss/gradient descent. Deliver simulated examples and scalar regression. |
| 13–16 | Define ML target and split; regression metrics; classification/thresholds; cross-validation/pipelines/imbalance/tuning. Deliver fair experiment and untouched test report. |
| 17–20 | Perceptron/MLP; losses and manual backprop; PyTorch tensors/autograd; optimizers/regularization. Deliver small trained classifier and debugging evidence. |
| 21–24 | CNN shapes; RNN/LSTM motivation; Q/K/V numerical attention; multi-head/masks/position/residual/norm. Deliver educational attention implementation and token-flow diagram. |
| 25–28 | Tokenization; pretraining/next-token objective; SFT/preferences/RLHF/DPO; decoding/KV cache/context/quantization. Deliver lifecycle and memory/cost worksheet. |
| 29–32 | Embeddings/similarity; ingestion/parsing/chunking; BM25/vector/hybrid/reranking; citations/abstention/evaluation. Deliver versioned RAG baseline. |
| 33–36 | RAG ACL/injection/deletion; durable ingestion/versioning; Spring AI boundary; streaming/structured outputs/errors. Deliver secure Spring AI slice. |
| 37–40 | Python typing/Pydantic/FastAPI; asyncio and blocking; REST/gRPC/queue; modular monolith vs services. Deliver integrated Java/Python flow and ADR. |
| 41–44 | Tool schemas/authorization; bounded agent loop; workflows/checkpoints/LangGraph; MCP resources/tools/prompts and approvals. Deliver controlled tool workflow. |
| 45–48 | Capacity/latency/SLO; queues/outbox/sagas/idempotency; Docker/CI/cloud/secrets; telemetry/load/cost. Deliver staging deployment and runbook. |
| 49–52 | Define an independent capstone; threat model and data model; implement the vertical slice; evaluate quality, load and privacy. Deliver a reviewable release candidate. |
| 53–56 | Capstone freeze/demo; interview banks; mock system designs; resume/portfolio/application plan. Deliver evidence-based career package. |

Each week passes only if you can explain the central mechanism from memory, reproduce or modify the artifact, test an edge/failure case, and name a limitation. Full topic-by-topic assignments and completion gates will be expanded with the subject notes.
