# Python Engineering

**Why learn Python:** most ML/data tooling and many model examples use Python. You need practical fluency to inspect datasets, train/evaluate small models, write a thin inference service, and collaborate with data/ML teams. You do not need to replace Java for every backend.

**Prerequisites:** programming experience; adapt examples to Java concepts you already know.

## Sequence

1. Syntax, values, control flow, collections, functions, modules and exceptions.
2. Files, JSON/CSV, pathlib, context managers, environments and dependency management.
3. Classes/dataclasses, iterators/generators, typing, testing, packaging.
4. NumPy/Pandas, vectorization, data validation and reproducibility.
5. Asyncio, blocking I/O, FastAPI/Pydantic and production boundaries.

See [Python fundamentals](Python-Fundamentals.md) for the first detailed chapter. The [AI From Scratch Python course](https://github.com/kavinash0310/ai-from-scratch/tree/main/course/python) is the companion subject volume. Later chapters must add production service patterns and Java/Python integration.
