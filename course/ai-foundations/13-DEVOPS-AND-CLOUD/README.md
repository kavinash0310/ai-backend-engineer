# DevOps and Cloud

Learn Linux/process/network fundamentals, Docker/Compose, CI/CD, one cloud, IAM, VPC/networking, storage, managed databases/queues, secrets, Terraform fundamentals, deployment/rollback, monitoring, logging, tracing, autoscaling, cost and production operations.

Study Java and Python service deployment separately where runtime/build differences matter. Then practice one system containing both. Production readiness means controlled configuration, least-privilege identity, health semantics, reproducible releases, telemetry, rollback, restore assumptions and incident runbooks—not merely a running container.
