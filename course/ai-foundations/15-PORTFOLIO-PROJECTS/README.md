# Portfolio projects

Build progressively larger projects and keep each scope reviewable.

1. **ML prediction service:** prepare data, train/evaluate, persist a model, expose an inference API, containerize it, and call it from Java.
2. **Document intelligence/RAG:** upload, parse, chunk, embed, hybrid-search, cite sources, enforce permissions, evaluate retrieval and answers.
3. **AI research workflow:** search adapters, source validation, evidence collection, synthesis/report, human approval; keep tools bounded and auditable.

Start with the detailed [evidence-grounded AI knowledge assistant project guide](01-ai-knowledge-assistant-project-guide.md), then extend it with the model and workflow projects above.

For each project include requirements, diagrams, ADRs, data/privacy notes, API contracts, evaluation plan, reproducible setup, demo, cost/latency measurements, failure behavior and known limits. A collection of unrelated demos is weaker than one coherent progression.
