# Interview Preparation

Build separate answer banks for Java/JVM/Spring/Hibernate/microservices/SQL; Python; data structures; ML/DL; transformers/LLMs; RAG; agents/MCP; system design/distributed systems; cloud; and AI security.

For every question, keep two answers: a concise interview response and a deeper explanation with assumptions, example, trade-offs, common follow-up and what the interviewer is testing. Practice coding, debugging, design and explaining a real project. Link existing Java question banks selectively; this repo adds AI-specific questions after the technical chapters are written.
