# AI foundations: from first principles to production

This is the theory and practice track inside the [AI Backend Engineer repository](../../README.md). It takes a learner from programming and mathematical foundations through classical AI, machine learning, deep learning, NLP, LLMs, retrieval, agents, evaluation, security and production operations.

## How this track fits the repository

Follow the main [Java/Spring Boot backend course](../java-spring/README.md) for production service implementation. Use this track to build model and AI literacy in enough depth to evaluate designs, explain behavior and understand trade-offs. Also use [AI From Scratch](https://github.com/kavinash0310/ai-from-scratch) as a companion reference for its broader AI/ML lessons. Existing theory in either repository remains useful; this track provides one connected, beginner-friendly sequence in this repo.

This course assumes little or no AI/ML knowledge. Java developers can use the diagnostic to skip programming topics they already demonstrate. The examples use small datasets and models; training a foundation model is not a prerequisite.

## Start here

1. Read the [learning roadmap](00-START-HERE/Learning-Roadmap.md) and [56-week study plan](00-START-HERE/Weekly-Study-Plan.md).
2. Take the [baseline diagnostic](00-START-HERE/Baseline-Diagnostic.md) and record evidence in the [progress tracker](00-START-HERE/Progress-Tracker.md).
3. Follow the [prerequisite graph](00-START-HERE/Prerequisite-Graph.md) and [curriculum map](00-START-HERE/Curriculum-Map.md).
4. Read [How to Study](00-START-HERE/How-to-Study.md) and use the [technology selection guide](00-START-HERE/Technology-Selection-Guide.md).
5. Learn in order, implement the exercises, explain the central mechanism from memory, test an edge/failure case, and record what you can demonstrate.

## Completion standard

A chapter is not complete because it was read. Show that you can explain the key idea, work a small example, implement or modify something, evaluate its behavior, name a limitation, and connect it to the next topic. For production claims, include security, latency, reliability and cost where relevant.

The 14-month schedule is an ambitious example for a sustained study pace; adjust it to your available time. Completing these materials structures learning but does not guarantee expertise or a job. Senior capability also requires ownership of real systems and experience making decisions under production constraints.
