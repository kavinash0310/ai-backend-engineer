# AI backend engineering projects

Build the projects in order. Each one should include a README, architecture diagram, local setup, API examples, tests, evaluation results, data/security notes, and known limitations. Reuse the [project rubric](../assessments/README.md).

1. [Model inference API](01-model-inference-api.md) — authenticated request, validated input, provider adapter, timeout, and cost tracking.
2. [Grounded RAG service](02-grounded-rag-service.md) — document ingestion, tenant-safe retrieval, citations, and evaluation.
3. [Production capstone](03-production-ai-backend-capstone.md) — queue, database, deployment, observability, security, and recovery.

Use synthetic or properly licensed data. Never commit API keys or private user information.
